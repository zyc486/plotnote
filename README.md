# PlotNote

一款纯前端的个人剧评记录应用，支持电视剧、电影、动画、书籍四种内容类型的观看记录管理。数据存储在浏览器本地（IndexedDB），无需后端服务。

## 技术栈

- **框架**：Vue 3 + Vite
- **状态管理**：Pinia
- **路由**：Vue Router 4
- **本地数据库**：Dexie (IndexedDB)
- **样式**：Tailwind CSS 3

## 启动

```bash
npm install
npm run dev
```

默认端口 5173，浏览器访问 `http://localhost:5173/`。

## 功能概览

### 内容管理（首页）

- **多分类支持**：电视剧、电影、动画、书籍，各自有独立的术语体系（集/部/章/卷/季/卷）
- **在线搜索添加**：集成 TVMaze（电视剧）、TMDB（电影）、AniList（动画）、豆瓣图书（书籍）四大数据源
- **手动添加**：支持自定义名称、季数、集数
- **系列管理**：可将多部作品归入同一系列（如漫威系列、哈利波特系列），首页可折叠/展开
- **状态管理**：想看、在看、看完、弃坑，首页卡片可一键快捷切换
- **封面图**：自动从数据源获取，缺失时可一键批量补全（TMDB 备用来源）
- **筛选与排序**：按分类、状态筛选，按名称/评分/最近观看排序

### 集数列表

- 网格展示所有集数，已评分的显示蓝色高亮和分数
- 多季作品支持按季筛选（水平滚动标签栏）
- 集数快速跳转（支持 `S5E10`、`5-10`、纯数字格式）
- 作品元信息展示（分类、状态、地区、类型标签）
- 封面图点击可放大查看
- 直接跳转到统计页

### 单集记录（核心编辑页）

- **评分**：0.0-10.0 滑块/数字输入，步长 0.1
- **感想**：支持 Markdown 语法，编辑/预览双模式切换
- **截图管理**：上传/粘贴图片，拖拽排序，每张可添加备注
- **标签系统**：预定义标签 + 自定义标签，支持搜索
- **多刷记录**：同一集可创建多条观看记录，可切换主记录
- **自动保存**：各字段独立防抖，离开页面前强制保存
- **集数导航**：底部上一集/下一集按钮，快速跳转面板

### 搜索（本地筛选）

- 按关键词搜索本地数据库（名称、评论、标签、地区、类型）
- 按分类、最低评分、标签多维度筛选
- 结果按匹配度排序

### 数据统计

- **总览视图**：全局作品/集数总数、全局均分、已评集数、分类分布、评分分布柱状图、月度观看趋势
- **作品详情视图**：单部作品的均分、最高/最低分集、各季平均分条形图

### 观看时间线

- 按月/日分组展示所有观看记录
- 显示分类图标、作品名、集数标签、评分、评论摘要
- 点击直接跳转到该集记录编辑页

### 数据管理

- **导出**：全量数据导出为 JSON 文件
- **导入**：从 JSON 文件恢复数据
- **自动备份**：每次数据变更后自动备份到 localStorage（5 秒防抖，4MB 上限，7 天过期）
- **备份恢复**：数据库为空时自动检测并提示恢复

### 其他

- 深色/浅色主题切换
- 纯前端架构，数据完全存储在浏览器本地
- 生产环境豆瓣图书 API 通过 allorigins.win 代理解决 CORS 问题

## 外部数据源

| 数据源 | 用途 | 说明 |
|--------|------|------|
| TVMaze API | 电视剧搜索与剧集数据 | 英文数据库，中文搜索依赖关键词映射 |
| TMDB API | 电影搜索与海报获取 | 默认使用内置 Key，支持自定义 API Key |
| AniList (GraphQL) | 动画搜索 | 日文/英文/中文多语言名称支持 |
| 豆瓣图书 | 图书搜索 | 开发环境走 Vite 代理，生产环境走公共 CORS 代理 |
